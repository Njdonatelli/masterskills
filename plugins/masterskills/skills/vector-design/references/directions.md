# Design Directions — Visual Reference

Each direction has distinct characteristics. Choose ONE based on brand mood.

---

## 1. Constructivist

**Vibe**: Bold, energetic, industrial
**Colors**: Red (#E63946), Black (#0D0D0D), White (#F4F4F4)
**Elements**: Diagonal lines, sharp angles, asymmetry, dramatic tension

```
Example structure:
- Background: solid black
- Diagonal red stripe across corner
- Bold caps text, rotated 2-3°
- Geometric icon (no curves)
```

**Best for**: Sports brands, energy drinks, fitness, streetwear

---

## 2. Bauhaus Geometric

**Vibe**: Foundation, architectural, timeless
**Colors**: Primary Red (#E63946), Blue (#1A365D), Yellow (#D69E2E), Black/White
**Elements**: Basic shapes (circle, square, triangle), type as structure, no decoration

```
Example structure:
- Split background (color block + white)
- Large circle as main element
- Text aligned to grid, black
- One primary color accent
```

**Best for**: Architecture firms, design studios, cultural institutions

---

## 3. Art Deco

**Vibe**: Luxury, glamour, sophistication
**Colors**: Gold (#D4AF37), Black (#0D0D0D), Cream (#F5F5DC)
**Elements**: Symmetry, geometric ornament, tall condensed caps, vertical lines

```
Example structure:
- Black background
- Gold geometric border pattern
- Tall condensed logo text
- Radiating lines from center
```

**Best for**: Jewelry, luxury hotels, premium services, real estate

---

## 4. Japanese Minimal

**Vibe**: Calm, intentional, premium restraint
**Colors**: Off-white (#FAFAFA), Charcoal (#333333), one accent (#E63946)
**Elements**: Extreme whitespace, single focal element, thin lines, hidden depth

```
Example structure:
- Off-white background
- Single small mark or icon
- Minimal text, generous margins
- Single accent color only
```

**Best for**: Tech SaaS, wellness, Japanese restaurants, minimalist brands

---

## 5. Swiss International

**Vibe**: Objective, trustworthy, clean
**Colors**: Black, White, one primary (red/blue)
**Elements**: Grid system, Helvetica-ish, flush-left, hierarchy through size

```
Example structure:
- White background
- Strong grid alignment
- Large headline, small body
- One color accent, minimal use
```

**Best for**: Finance, healthcare, government, institutional

---

## 6. Corporate Modernism

**Vibe**: Professional, modern, data-driven
**Colors**: Navy (#1A365D), slate gray (#4A5568), white
**Elements**: Clean sans-serif, subtle gradients, rounded corners, modern shadows

```
Example structure:
- Navy gradient background
- Centered logo mark
- Clean hierarchy
- Minimal data visualization accent
```

**Best for**: Tech startups, B2B services, corporate software

---

## 7. Kinetic / Motion Forward

**Vibe**: Dynamic, fast, forward-thinking
**Colors**: High contrast, speed accent
**Elements**: Diagonal text, motion lines, overlapping shapes, translucent layers

```
Example structure:
- Fast diagonal composition
- Overlapping translucent shapes
- Text at angles
- Motion blur lines
```

**Best for**: Delivery apps, sports streaming, fintech

---

## 8. Organic / Natural

**Vibe**: Grounded, warm, approachable
**Colors**: Earth tones (#8B7355, #556B2F), cream, terracotta
**Elements**: Rounded forms, botanical motifs, hand-drawn feel, natural textures

```
Example structure:
- Cream/earth background
- Soft organic shapes
- Botanical line work
- Warm accent colors
```

**Best for**: Restaurants, cafes, skincare, organic brands

---

## 9. Contemporary Editorial

**Vibe**: Magazine-cover, confident, current
**Colors**: Restrained (black, white, one bold color)
**Elements**: Large display numbers, mixed weights, generous negative space

```
Example structure:
- 80% negative space
- Giant number or letter
- Small crisp body text
- Single bold accent
```

**Best for**: Events, publications, cultural programs

---

## 10. Retro Letterpress

**Vibe**: Vintage, authentic, warm
**Colors**: Kraft brown (#C4A77D), ink black, cream
**Elements**: Subtle noise texture, ink-trap serifs, imperfect registration

```
Example structure:
- Textured cream background
- Dark serif text with slight offset
- Simple border frame
- Authentic worn feel
```

**Best for**: Coffee roasters, artisan goods, heritage brands

---

## Choosing the Right Direction

**Ask the user**:
1. Industry?
2. Target audience?
3. Desired mood/feeling?

**Match to direction** using the mood table in SKILL.md.

**Show swatches** before full design. Get user alignment on ONE direction.

**Commit fully** — don't mix philosophies. Premium design = coherent execution of one vision.
