# Owner profile: facts ledger (template)

Copy this file to `profile.md` and fill it in by interviewing the owner. `profile.md` is private: keep it out of version control.

Drafts may state only what is under "Known" (or what the owner says in the session, or what a file read in the session shows). If a project file and this profile disagree on a fact, the file wins: use the file and correct the line here. Add new durable facts with the date the owner gave them.

## Known

- Name, and the name he publishes or trades under.
- What he sells, and to whom.
- Each product or service: what it is, what it does, what it does not do. Give the file each fact came from.
- Any figure he is happy to make public.

## Owner decisions (these override the skill's other files)

- First person or "we".
- Whether the tools used to make the work may be mentioned, and in which kinds of post.
- Sale details: whether drafts may carry price, link or where-to-buy.
- Audience, and the goal of posting.
- Reading level: trade terms or layman's terms.

## Not known: ask, or mark [CONFIRM]

- Anything a draft might need that he has not said: history, clients, usage, reviews, photos.

## Never say

- Claims he has ruled out.
- Invented history or numbers.
