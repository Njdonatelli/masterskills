# Owner profile: job search (template)

Copy this file to `profile.md` and fill it in by interviewing the owner. `profile.md` is private. Keep it out of version control. The repo `.gitignore` already excludes it.

Screens and drafts may state only these facts:

- The facts under "Career facts".
- What the owner says in the session.
- What a file read in the session shows.

Add new facts with the date the owner gave them.

## Career facts

- Degrees: school, field, concentration, year.
- Each job: employer, exact title, start and end month, duties, tools. Give the source of each fact (resume file, the owner).
- Contract and freelance work: client type, dates, what was built, tools.
- Licenses and certifications, with expiry dates.
- Gaps in employment, and the reason the owner gives for each.

## Job-search rules (owner decisions)

- Location and commute: home base, maximum commute, allowed areas, and named exceptions.
- Work mode: on-site, hybrid, or remote. State the rule for postings outside the commute area.
- Employment types that count: W-2 full-time, part-time, contract, retainer.
- Titles or levels to skip.
- Employer rules: any employer type to include only under conditions, and the conditions.
- Weekly targets, if the owner tracks them.

## Records

- Tracker: name and location of the sheet or file that logs applications.
- Where application files go: folder or drive.
- Preferred file format for resumes and letters.

## Not known: ask

- Any requirement a posting names that the facts above do not answer, for example a software tool or a license.
