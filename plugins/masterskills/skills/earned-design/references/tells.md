# Tells: a diagnostic for the finished render

Read this after rendering, never before designing. Each row is a symptom. A hit means a decision was skipped; the third column names it. Fix the decision.

A row does not apply when the element is fixed by a governing design system or brief, or when you can give its "because" and the because fails the swap test.

The list dates fast. Published tell lists already contradict each other: one creator's fix (cream page, serif, small mono labels, hairline rules) is another creator's list of tells. The swap test outlives every list, so trust it over any row here.

## Ground and colour

| Tell | Stands in for | Decide instead |
| --- | --- | --- |
| Purple-to-blue gradient on header, button or chart fill | No colour decision | What is the one thing colour must mean here? Give it one flat hue. |
| Glowing radial blobs behind a hero | Nothing to say in that space | Say something there or leave it empty. |
| Cream or beige ground with terracotta accent | The escape from the gradient | What ground does the subject's own material have? |
| Near-black with one neon accent and glowing borders | "Developer" or "premium" as a category | Who uses this, and under what light? |
| A different pastel for each card or icon | Decoration counted as information | Does colour encode anything? If not, remove it. |
| Mid-paragraph text dimmed to grey | Emphasis without a ranking | Cut the weaker sentence or leave it at full strength. |

## Type

| Tell | Stands in for | Decide instead |
| --- | --- | --- |
| One italic or coloured word in every headline | A headline with no point | Rewrite the headline so the whole line carries it. |
| The current fashionable display serif, or the stock UI sans as display | No type decision | What does lettering look like in the subject's world? |
| Mono type on labels, pills and metadata everywhere | "Technical" as a costume | Mono only where the text is a value, code or ID. |
| Tight negative tracking on big uppercase | Borrowed drama | Does the size already do the work? |
| Heavy condensed sans headline on off-white or pale grey, one loud accent | The escape from the editorial serif | What does lettering in the subject's world look like? |

## Structure

| Tell | Stands in for | Decide instead |
| --- | --- | --- |
| Grid of identical cards (icon, heading, two lines) | No ranking | Step 3. What leads? |
| Four KPI cards, same size, same badge | No ranking | One primary, the rest compact. |
| Large radius and drop shadow on everything | No model of depth | What actually floats? Shadow only that. Radius scales with element size. |
| Every section wrapped in a bordered container | Avoiding layout | Group with space and alignment first. |
| A rule above and below every row | Structure added, not found | Which separations does the reader need? |
| Centered hero, three features, testimonial row, final call to action | The category template | What does this visitor need second? Third? |
| Dense screen crammed with tiny badges and widgets | Looking capable | What does the scene need on this screen? |

## Labels and furniture

| Tell | Stands in for | Decide instead |
| --- | --- | --- |
| Uppercase tracked eyebrow above every heading | Furniture | Does the label tell the reader something the heading does not? |
| "01 / 02 / 03" on sections that are not a sequence | Fake order | Number only real sequences. |
| Pills and tags on everything | Fake taxonomy | Is it a status or filter the reader uses? |
| `// comment` breadcrumbs, ASCII art, dithering, coordinates | Atmosphere from another subject | Would this subject have it? |
| Emoji as icons or list bullets | No icon decision | Plain text, or one consistent icon set, or nothing. |
| An icon tile on every card | Filling space | Let the number or the heading be the object. |

## Copy

| Tell | Stands in for | Decide instead |
| --- | --- | --- |
| Two-fragment titles ending in periods ("Plans first. Acts second.") | Rhythm in place of content | State the claim in one plain sentence. |
| "Welcome back, Name" with a waving hand | No header content | Name the thing on screen and its period. |
| Three paragraphs saying one thing | No edit | Say it once. |
| Copy a competitor could publish unchanged | No subject | Step 2. What is true only here? |
| Invented testimonials, logos, user counts | No proof | Real proof or none. |
| "Learn more", "Get started" | No intent | Name the action and its object. |
| Copy that describes the page's own design or metaphor | A move that is not landing | Fix the move or cut it. The page never explains itself. |

## Data

| Tell | Stands in for | Decide instead |
| --- | --- | --- |
| "+12.5%" pill on every metric | Numbers with no shape | Unit, period, comparison. Plain text. |
| Round, even, plausible numbers | Placeholder data | Real figures, or label as sample. |
| No named period | No context | State the date range. |
| Proportional digits in columns | Skipped finish | Tabular figures. |
| Chart title names the axes | No finding | Title states what the chart shows. |

## Decks and documents

| Tell | Stands in for | Decide instead |
| --- | --- | --- |
| Title slide, agenda, three-bullet slides, "Thank you" | The deck template | One claim per slide; cut slides with no claim. |
| Every slide the same layout | No ranking across the deck | Which slide is the point? Give it the room. |
| Headings that label ("Overview", "Key findings") | No claim | Headings that state the finding. |
| Summary that repeats the body | No edit | Lead with the ask; cut the recap. |
| An icon beside every bullet | Filling space | Fewer bullets, or a table. |
